LangChain Integration

This guide shows how to use arango‑typed with LangChain to build RAG (Retrieval‑Augmented Generation) systems. You will: (1) ingest documents with embeddings, (2) retrieve by semantic similarity, and (3) wire retrieval into an LLM chain.

Prerequisites

  • arango‑typed and arangojs installed.
  • An embeddings provider (OpenAI, local model, etc.).
  • LangChain core packages installed.
npm install @langchain/core @langchain/textsplitters
# if using OpenAI embeddings
npm install openai

Indexing workflow

  1. Split text into chunks.
  2. Create embeddings for each chunk.
  3. Store chunk + embedding into an ArangoDB collection via arango‑typed VectorSearch.
import { RecursiveCharacterTextSplitter } from '@langchain/textsplitters';
import { getVectorSearch } from 'arango-typed';

const splitter = new RecursiveCharacterTextSplitter({ chunkSize: 1000, chunkOverlap: 150 });
const chunks = await splitter.splitText(longText);

const vs = getVectorSearch();
for (const text of chunks) {
  const embedding = await embed(text); // your embedding fn
  await vs.store('docs', { text, embedding });
}

Retrieval

Retrieve relevant chunks using cosine similarity. You can tune topK and scoreThreshold, and enable pre‑computed magnitudes for performance.

const queryEmbedding = await embed(userQuery);
const results = await vs.similaritySearch('docs', queryEmbedding, {
  topK: 6,
  scoreThreshold: 0.65,
  usePrecomputedMagnitudes: true
});
const context = results.map(r => r.text).join('\n\n');

RAG with LangChain

Send the retrieved context to your LLM in the prompt. The snippet below demonstrates a minimal retrieve‑then‑generate loop; adapt to your LangChain model/provider.

import { ChatPromptTemplate } from '@langchain/core/prompts';
// import your chosen chat model from LangChain integrations

const prompt = ChatPromptTemplate.fromTemplate(`You are a helpful assistant.
Use the provided context to answer the question.
Context:\n{context}\n\nQuestion: {question}`);

const chain = prompt.pipe(model); // where model is a LangChain chat model
const answer = await chain.invoke({ context, question: userQuery });

Design notes & tips

  • Chunking: For long documents, prefer 800–1200 tokens with 10–20% overlap.
  • Filtering: Add metadata (tenantId, tags) and filter during retrieval for better relevance.
  • Hybrid search: Combine text + vector with hybridSearch when keyword precision matters.
  • Performance: Enable pre‑computed magnitudes and result caching; index metadata fields.
  • Freshness: Maintain an "updatedAt" field and periodically re‑embed changed content.

End‑to‑end flow (summary)

  1. Split → embed → store via VectorSearch.store().
  2. Embed query → retrieve via similaritySearch / hybridSearch.
  3. Build prompt with retrieved context → call LLM.
  4. Iterate: evaluate relevance, tune chunking/thresholds.
