Performance

Best practices and built‑in features to make arango‑typed fast and efficient.

Connection reuse

import { connect } from 'arango-typed';
await connect('http://localhost:8529/myapp', { username: 'root', password: '' });
// Subsequent calls with the same parameters reuse the cached connection.

Query caching

// Repeated queries with the same structure reuse compiled AQL
await User.find({ name: 'John' }).all();
await User.find({ name: 'Jane' }).all();

Compiled validators

schema.validateSync({ name: 'John' }); // Compiles once, then reuses

Direct DB writes (no hooks)

// If no pre/post save hooks, create() uses direct DB access for speed
await User.create({ name: 'NoHooks' });

Indexing

UserSchema.index(['tenantId', 'email']); // compound index improves tenancy queries
