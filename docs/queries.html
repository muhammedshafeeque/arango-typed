Queries

Use the chainable query builder for readable, type‑safe AQL generation.

Find

const adults = await User.find({ age: { $gte: 18 } }).all();

Find one / by id

const u = await User.findOne({ email: 'john@example.com' });
const byId = await User.findById('users/123');

Projection and sort

const users = await User.find({ active: true })
  .select(['name','email'])
  .sort({ createdAt: -1 })
  .limit(20)
  .all();

Pagination

const page2 = await User.find({}).skip(20).limit(20).all();

Aggregation

const count = await User.aggregate().match({ active: true }).count();

Index hints

const q = User.find({ email: 'a@b.com' }).hint('idx_email');

Lean reads

const list = await User.findLean({}).all(); // plain objects, faster
