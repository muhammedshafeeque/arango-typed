Aggregation & Calculations

Use the aggregation builder for counts, grouping, and calculations without writing raw AQL.

Count

const activeUsers = await User.aggregate()
  .match({ active: true })
  .count();

Group by

const byCountry = await User.aggregate()
  .group({ _by: ['country'], total: { $sum: 1 } })
  .sort({ total: -1 })
  .limit(10)
  .all();

Sum / Avg / Min / Max

const stats = await Order.aggregate()
  .match({ status: 'paid' })
  .project({
    revenue: { $sum: '$amount' },
    avgAmount: { $avg: '$amount' },
    minAmount: { $min: '$amount' },
    maxAmount: { $max: '$amount' }
  })
  .first();

Pipeline example

const topTags = await Post.aggregate()
  .unwind('$tags')
  .group({ _by: ['tags'], total: { $sum: 1 } })
  .match({ total: { $gte: 5 } })
  .sort({ total: -1 })
  .limit(20)
  .all();
