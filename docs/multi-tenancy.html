Multi‑tenancy

Enable tenant isolation with automatic filtering and Express middleware.

Express middleware

import { tenantMiddleware } from 'arango-typed/integrations/express';
app.use(tenantMiddleware({ extractFrom: 'header' })); // x-tenant-id

Model configuration

const User = model('users', UserSchema, { tenantEnabled: true });
// All queries auto-filter by tenant; create auto-injects tenantId.

Best practices

  • Index tenant field (`tenantId`).
  • Prefer composite indexes: [`tenantId`, `email`].
  • Use `findLean` for read-heavy endpoints.
