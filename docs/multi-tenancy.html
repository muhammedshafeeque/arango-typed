Multi‑tenancy

arango‑typed provides automatic tenant filtering at the model level and a middleware to extract the tenant from requests. This minimizes leakage risk and removes boilerplate from every query.

Concepts

  • TenantContext: request‑scoped holder for the active tenantId.
  • Automatic filtering: when tenantEnabled: true, all model queries add { tenantId: activeTenant } under the hood.
  • Automatic injection: create()tenantId to new docs.

Enable on a model

const User = model('users', UserSchema, { tenantEnabled: true, /* tenantField defaults to 'tenantId' */ });
// All reads/writes are scoped to the active tenant automatically.

Extract tenant in Express

import { tenantMiddleware } from 'arango-typed/integrations/express';

// Common: header (x-tenant-id)
app.use(tenantMiddleware({ extractFrom: 'header' }));

// Alternatives
app.use(tenantMiddleware({ extractFrom: 'query', queryParam: 'tenant' }));
app.use(tenantMiddleware({ extractFrom: 'params', paramName: 'tenantId' }));
app.use(tenantMiddleware({ extractFrom: 'jwt', jwtPath: 'org.id' }));
app.use(tenantMiddleware({ extractFrom: 'custom', customExtractor: (req) => req.getTenant?.() ?? null }));

// Make tenant mandatory (400 if missing)
app.use(tenantMiddleware({ extractFrom: 'header', required: true }));

Lifecycle (context)

The middleware sets TenantContext at request start and clears it when the response finishes.

// Pseudocode
TenantContext.set(tenantId);
// ... all model calls are scoped ...
TenantContext.clear();

Indexes & performance

  • Create an index on the tenant field: tenantId.
  • For lookups with another field, prefer composite indexes, e.g., [tenantId, email].
  • Use findLean() for read‑heavy endpoints to skip document wrappers.

Isolation strategies

  • Shared DB, tenant field (default): simplest; add tenantId to documents and index it.
  • Database‑per‑tenant: set different databaseName per request; higher isolation; heavier ops.
  • Collection‑per‑tenant: advanced pattern; only when required for sharding or legal separation.

Testing

import { TenantContext } from 'arango-typed/tenancy/TenantContext';

beforeEach(() => TenantContext.set('testTenant'));
afterEach(() => TenantContext.clear());

Common pitfalls

  • Missing index on tenantId → slow queries.
  • Bypassing the model layer with raw AQL without including tenantId filter.
  • Returning cross‑tenant references in aggregations (ensure each stage keeps tenant filter).
