Relationships

Model relations between documents using helpers, similar to ORMs.

HasOne

User.hasOne('profile', Profile);
const profile = await user.$related.profile();

HasMany

User.hasMany('posts', Post);
const posts = await user.$related.posts();

BelongsTo

Post.belongsTo('user', User);
const owner = await post.$related.user();

BelongsToMany

User.belongsToMany('roles', Role, { through: 'user_roles' });
const roles = await user.$related.roles();

Polymorphic

Comment.belongsTo('commentable', { polymorphic: true });
const parent = await comment.$related.commentable();
