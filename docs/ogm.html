OGM (Graphs)

Work with vertices and edges using convenient OGM helpers.

Create a GraphModel

import { getDatabase, graphModel, Schema } from 'arango-typed';
const db = getDatabase();
const UserSchema = new Schema({ name: String });
const UserGraph = graphModel(db, 'social', 'users', UserSchema);

Traverse relationships

const friends = await UserGraph.getOutbound('users/alice', 'friends');
const followers = await UserGraph.getInbound('users/alice', 'follows');
const connected = await UserGraph.getConnected('users/alice', 'friends');

Create relationships

await UserGraph.createRelationship(
  'users/alice', 'users/bob', 'friends', { since: new Date() }
);

Paths

const path = await UserGraph.getPath('users/alice', 'users/charlie');
