Vector Search

Built‑in vector search with cosine similarity, Euclidean distance, and hybrid scoring. Includes performance optimizations like pre‑computed magnitudes and caching.

Store Documents with Embeddings

import { getVectorSearch } from 'arango-typed';

const vs = getVectorSearch();
await vs.store('documents', {
  text: 'ArangoDB is a multi-model database',
  embedding: await embed('ArangoDB is a multi-model database')
});

Cosine Similarity

const results = await vs.similaritySearch(
  'documents',
  queryEmbedding,
  { topK: 5, scoreThreshold: 0.7, usePrecomputedMagnitudes: true }
);

Euclidean Distance

const results = await vs.euclideanSearch('documents', queryEmbedding, { topK: 10 });

Hybrid Search

const results = await vs.hybridSearch(
  'documents',
  queryEmbedding,
  {
    textQuery: 'multi-model database',
    weights: { text: 0.4, vector: 0.6 },
    topK: 10
  }
);

Performance Tips

  • Enable pre‑computed magnitudes on documents to speed cosine similarity.
  • Use caching for repeated queries with similar structure.
  • Limit returned fields where possible; prefer lean reads for listing.
