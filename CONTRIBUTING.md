# Contributing to Arango Typed

Thank you for your interest in contributing to Arango Typed! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/arango-typed.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature-name`

## Development

### Building

```bash
npm run build
```

### Testing

```bash
npm test
```

### Linting

```bash
npm run lint
```

## Code Style

- Use TypeScript with strict mode
- Follow existing code style
- Add JSDoc comments for public APIs
- Write tests for new features

## Pull Requests

1. Make sure tests pass: `npm test`
2. Update documentation if needed
3. Submit a pull request with a clear description

## Reporting Issues

Please use GitHub Issues to report bugs or request features. Include:
- Description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Environment details (Node.js version, etc.)
